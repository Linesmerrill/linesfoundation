Stream Deck Home

A small personal project that puts the house's smart devices on an Elgato Stream Deck.

Each key shows a device's live state and switches it with one press — a Kasa smart plug on or off, or a Nest thermostat off and back to the mode it was in. It runs only on the owner's own Mac and controls only the owner's own devices.

It is not a public service: there are no accounts to create and nothing to sign up for.
