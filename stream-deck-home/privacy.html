Privacy Policy

Stream Deck Home · Last updated September 12, 2026

Stream Deck Home is a personal project that lets its owner control their own smart-home devices from an Elgato Stream Deck. It is not offered to the public.

What it accesses

With the account holder's permission, given on Google's consent screen, it uses the Google Smart Device Management API to read the state of Nest thermostats (name, room, mode, and current temperature) and to change a thermostat's mode. It also reads and switches the account holder's Kasa smart plugs through TP-Link's cloud service.

How the data is used

Device information is used only to show each device's current state on the Stream Deck and to carry out the key presses the owner makes. It is not used for advertising, analytics, or any other purpose.

Storage

Sign-in tokens are stored only on the owner's own computer, in the macOS Keychain. Device data is held in memory while the app runs; the only thing written to disk is the last mode each thermostat was in, so it can be restored. Nothing is stored on any server operated by this project.

Sharing

No data is sold, shared, or transferred to anyone. Requests go directly from the owner's computer to Google and TP-Link.

Google API Services

Stream Deck Home's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from your Google Account's third-party connections. Revoking it stops the app from reading or controlling any Nest device.
